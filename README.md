# Before you begin, ensure you have the following installed on your machine:
- Node.js (which includes npm) ~ https://chatgpt.com/c/f33ded4e-abe2-44ef-8a62-b4517ac167ca#:~:text=official%20Node.js%20website
- Go ~ https://chatgpt.com/c/f33ded4e-abe2-44ef-8a62-b4517ac167ca#:~:text=official%20Golang%20website
- MySQL

# Setup Backend Golang
- `cd gym`
- create .env file and follow the example from `.env-example` file
- open terminal run `go mod tidy`
- run `go run main.go`

# Setup Frontend React
- in new terminal from GYM folder run `cd app && cd frontend`
- run `npm i`
- run `npm start`

done.
